# Knowledge base (AI-assisted)

How the mod's systems work, and what we learned building them, mistakes included, so the next
change doesn't repeat them. One page per system.

- `point-lights.md`: lights from glowing particles, flicker, Jak's shadow spheres
- `surface-lights.md`: fires, lava and lamps from the level's palette slots
- `water.md`: waves, wakes, clear water, shore foam
- `rendering-facts.md`: facts about OpenGOAL's renderer this mod relies on
